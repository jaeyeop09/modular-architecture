# Modular Architect

내진 설계 미션이 포함된 2D/3D 건축 공간 설계 웹 애플리케이션입니다.

## 실행

GitHub Pages에서 정적 사이트로 실행할 수 있습니다. `index.html` 하나로 구성되어 있으며 Three.js는 CDN에서 불러옵니다.

## 핵심 기능

- 2D 평면도 편집
- 벽/문/창문/기둥/바닥/계단/지붕/가구 배치
- 2cm Snap 및 방향키 2cm 이동
- X/Y/크기/높이/회전 직접 입력
- 삭제, 실행 취소/다시 실행
- JSON 저장/불러오기
- 하나의 객체 데이터로 2D ↔ 3D 동기화
- Three.js 기반 3D 뷰
- 내진 설계 학습용 미션 검사

## GitHub Pages

Repository Settings → Pages → Deploy from a branch → main / root 를 선택하면 됩니다.
